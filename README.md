# Zomboys

Lead a four-man squad through the zombie apocalypse.

**Download:** https://zomboys.vercel.app (always the newest build) · or grab `Zomboys-mac.zip` from the [latest release](https://github.com/imit/zomboys/releases/latest).

This repository only hosts release builds.

macOS: unzip, then right-click `Zomboys.app` → Open the first time (the build is not notarized).
